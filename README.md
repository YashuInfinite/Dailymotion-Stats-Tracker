## 🚀 About

**Dailymotion Stats Tracker** is a lightweight web application that allows you to quickly retrieve public statistics from Dailymotion.

You can select a metric and provide either a **Dailymotion channel** or **video URL** to retrieve the corresponding statistics.

### Available Statistics

- 👥 Channel Followers
- 👁️ Video Views

The application communicates directly with the Dailymotion API and displays the results in a clean, responsive interface.

---

## ✨ Features

- 📊 Fetch channel follower counts
- 👁️ Fetch video view counts
- 🔗 Accept Dailymotion channel URLs
- 👤 Accept Dailymotion usernames
- 🎬 Accept Dailymotion video URLs
- ✅ Validate Dailymotion URLs
- ⚡ Fetch statistics directly from the API
- 🔄 Switch between Followers and Views
- ⏳ Loading animation
- ❌ User-friendly error messages
- 📱 Responsive design
- 🌙 Modern dark UI
- 💎 Glassmorphism-style interface
